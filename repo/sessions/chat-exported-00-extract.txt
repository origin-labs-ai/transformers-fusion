2.  **High-RAM Mode:** Agar tera pass Colab Pro/Pro+ nahi hai, toh free tier mein kabhi-kabhi high-RAM option mil jaata hai (luck pe depend karta hai).
3.  **Kaggle Notebooks:** Agar Colab limit hit kar raha hai, toh Kaggle try kar. Wahan bhi free GPU/TPU milti hai aur sometimes limits thodi alag hoti hain.
4.  **Lightning.ai / Paperspace Gradient:** Yeh platforms bhi free tiers dete hain jo Colab jaise hi hain.

```python
# bitsandbytes + transformers use kar
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.float16,
    bnb_4bit_use_double_quant=True,
    bnb_4bit_quant_type="nf4"
)

# Dono models 4-bit mein load honge ~6GB VRAM each
llama_8b = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.1-8B-Instruct", quantization_config=bnb_config)

```
